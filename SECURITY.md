# Security policy

koulaxizis.gr is a static site with no accounts, forms, cookies or tracking.

## Reporting a vulnerability

Email koulaxizis@glarolykoi.net with the subject "Security: koulaxizis.gr".
Please do not open a public issue for a security problem.

You will get a reply within 7 days. Fixes ship as a pull request and are
noted in the commit history. Reports are kept private until fixed.
